# Rank Marketing — Central de Marketing

Gerador de propostas comerciais e apresentações da RankMyApp.

## Arquivos
- `Gerador de Propostas.dc.html` — gerador de propostas (seleção de produtos, módulos, slides, exportação)
- `RankMyApp Apresentacao Template.dc.html` — template de apresentação
- `RankMyApp Apresentacao Comercial.dc.html` — apresentação comercial
- `proposta-model.js` — modelo de dados das propostas
- `deck-stage.js`, `support.js` — runtime
- `assets/`, `src/` — imagens e recursos

## Uso
Abra os arquivos `.dc.html` diretamente no navegador (sirva a pasta via servidor local, ex.: `npx serve .`).
